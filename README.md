# Organizador de Archivos

Script de automatización en Bash que organiza archivos en carpetas según su tipo, fecha o extensión.

## Uso

```bash
bash organizador.sh
```

## Funcionalidades

- Organiza archivos por extensión (imágenes, documentos, videos, etc.)
- Organiza por fecha de modificación
- Evita mover archivos que ya están organizados
